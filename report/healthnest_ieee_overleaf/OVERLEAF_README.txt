HealthNest report - IEEE conference format (IEEEtran)

1. Go to overleaf.com -> New Project -> Upload Project -> choose healthnest_ieee_overleaf.zip.
2. Menu -> Main document: healthnest_ieee.tex. Compiler: pdfLaTeX (the default).
3. Click Recompile.

Before submitting:
- Check the author names, department and university in the \author block (marked TODO).
- Figures and tables are generated from the evaluation results by report/make_figures.py in the
  project repository; re-run it after any new experiment instead of editing numbers by hand.
- The course asked for references in the format "Author, A., Year, Month. Title. In Venue (pp. x-y)."
  The entries use that format with IEEE-style numbered citations [n] in the text.
