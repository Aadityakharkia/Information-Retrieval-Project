Information Retrieval System Architecture

HealthNest implements core IR principles from lectures to ensure verifiable, trustworthy medical Q&A.

The 9-Step HealthNest Pipeline

  1. CSV Dataset Loading: Flexible schema reader mapping Kaggle Q&A CSV rows.
  2. Document Chunking: Sentence windowing & token granularity control.
  3. Text Normalization & Hinglish Lexicon: Devanagari regex + synonym expansion.
  4. Hand-written Inverted Index: Question & Body multi-zone postings lists.
  5. SMART lnc.ltc TF-IDF Vector Space Model: Log-tf, IDF, cosine normalization.
  6. Dense Embeddings: SentenceTransformers cosine similarity via matrix operations.
  7. Reciprocal Rank Fusion (RRF): Hybrid rank aggregation ($k=60$).
  8. Selective Abstention: Evidence strength thresholding ("I don't know").
  9. Fact Verification Checker: Sentence-level sparse cosine & dosage number verification.
