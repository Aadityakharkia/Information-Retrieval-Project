# HealthNest - AI Usage & Team Code Review Log

This log documents all modules generated by the AI coding assistant across project phases, along with specific verification steps and code review tasks for team members.

---

### Phase 0: Repository Skeleton, Config, Loader
- **Generated Files**: `config.py`, `.gitignore`, `requirements.txt`, `backend/data/loader.py`
- **What Was Done**: Built dataset loader with CSV column auto-detection, null row dropping, question deduplication, and synthetic fallback dataset generator.
- **Team Review Tasks**:
  - Verify `CSV_COLUMN_MAPPING` in `config.py` against Kaggle dataset header names.
  - Review emergency phone numbers (default: 112 in India).

---

### Phase 1: Text Processing, Inverted Index, TF-IDF, BM25
- **Generated Files**: `backend/ir/text.py`, `backend/ir/hinglish.py`, `backend/ir/inverted_index.py`, `backend/ir/tfidf.py`, `backend/ir/bm25.py`, `tests/test_ir_core.py`, `scripts/demo_cli.py`
- **What Was Done**: Implemented Unicode NFKC normalization, Devanagari regex `[\w\u0900-\u097F]+`, Porter Stemming, English/Hinglish stop-word filtering, Hinglish lexicon expansion (`lexicon_hinglish_health.tsv`), hand-written multi-zone inverted index, SMART lnc.ltc TF-IDF cosine retriever, and Okapi BM25 retriever.
- **Team Review Tasks**:
  - Review and expand `data/lexicon_hinglish_health.tsv` with additional Hindi/Hinglish medical phrases (~60+ entries currently).
  - Verify hand-computed toy corpus math in `tests/test_ir_core.py`.

### Phase 2: Dense Embeddings & Hybrid Fusion
- **Generated Files**: `backend/ir/dense.py`, `backend/ir/hybrid.py`, `scripts/build_index.py`
- **What Was Done**: Implemented `SentenceTransformer` (`paraphrase-multilingual-MiniLM-L12-v2`) dense vector search with numpy matmul cosine similarity, Reciprocal Rank Fusion (RRF, $k=60$), and index builder caching script.
- **Team Review Tasks**:
  - Verify dense embedding matrix shape `(N, 384)` in `data/processed/dense_embeddings.npy`.
  - Benchmark sparse vs dense execution latency on laptop CPU.

### Phase 3 & 4: RAG Pipeline, Abstention, Generation, Safety, Fact Checker
- **Generated Files**: `backend/rag/llm_client.py`, `backend/rag/prompt.py`, `backend/rag/abstain.py`, `backend/rag/generator.py`, `backend/rag/checker.py`, `backend/rag/safety.py`, `backend/pipeline.py`

### Phase 10: Rocchio Relevance Feedback
- **Generated/Changed Files**: `backend/ir/rocchio.py`, `TfIdfRetriever.search_weighted`, `DenseRetriever.search_vector`, `backend/pipeline.py`, `backend/app.py`, `frontend/answer.html`, `frontend/js/answer.js`, `eval/model_comparison/rocchio_eval.py`, tests.
- **What Was Done**: "More like this / Not relevant" buttons (explicit Rocchio feedback) and optional pseudo-relevance feedback, measured on the 40 needs in three languages.
- **Results**: explicit feedback (simulated, residual collection) nDCG@10 0.274 -> 0.365, p < 0.001; pseudo feedback +0.007, not significant, so it is off.
- **Team Review Tasks**:
  - The explicit-feedback result assumes a user who marks perfectly; real users will be noisier.
  - Try the buttons on Hinglish questions and check the "words added to the search" line in the IR Inspector.
